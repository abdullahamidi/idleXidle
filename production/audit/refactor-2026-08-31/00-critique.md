## 4. The fifteen most consequential findings for the refactor plan (ranked)

1. **`SkillId` never reaches the fight; `(Form, Passive)` is the skill's identity in the save, the pick, the composer and every `EquippedSkill.Def` read.** `SavedSkill` has no `SkillId` (`SaveGame.cs:294-310`); `PlayerLoadout.SaveSkills/Restore/ToBuild` drop it (`:268, 278-292`); `Build.cs:255-256` re-resolves `SkillCatalogue.Resolve(Form, Passive)` on every one of ~21 hot-path reads; `BuildComposer.cs:87,171` "THE ID WINS" is unreachable everywhere. Every Form-deletion step is blocked until SkillId is threaded save → pick → `EquippedSkill` **in one commit**, with `CurrentVersion = 3` (old builds must say "newer version", not "corrupt"), an RHB1-tolerant share-code decoder (plus the third format, `SharedFeedback`/RHF), a `(Form, effective slot kind) → SkillId` table (not name→id — `Passive` picks which of the style's two skills), and a JSON fixture of a real pre-08-30 save asserting the composed `Def.Id`. Unanimous across seven verifiers; absent from every report's plan.

2. **The variation/reinforcement layer is dormant in real play** (G1). One missing argument at `SoloExpeditionScreen.cs:775` (also `WeaveScreen.cs:610,1370`, `StatsScreen.cs:174`) means the player buys 24 variations and 73 reinforcements that never fire; 97 green liveness rows mask it. Fixing it lights up ~40 SkillDef dials for the first time with untuned numbers (SIGN 1.6×(1+2.0)=4.8×, GLUT "No lifesteal" heals 12%, JAWS "3 s" re-arms at 8 s, VENGEANCE has no window, CLUSTER is a 5× nerf). Fix + balance pass + hunt-path test.

3. **Form is the sim's key, and `SkillDef` has no base-damage dial.** Base damage (`FormBaseValue`, four sites), affinity hexagon (four), Field/Reaction target baseline (three), amplify/heal forks (five), REND/EXECUTE/OVERDRAW gates (three), WEAVER echo (which prices PRESS as a 500 Strike, MIRE/PULSE as 12, skips REPAY), the 8 000 ms Trap re-arm, and the `BattleEvent` payload. Six null-`LegacyForm` skills borrow a sibling's numbers (PULSE casts 12; base JAWS runs on the 290 fallback; base DRINK heals via `Heals(form)` not `Lifesteal`). Each replacement is an authored number or a design decision, not a rename — the reports' "C-replace" tables understate this.

4. **Swapping the Form hexagon for the Style ring is a balance change.** Opposite pairs differ; every affinity/family/parity test number moves; `FormHexDiagram`, `WeaveScreen.cs:1108-1109`, five "ADEPT" titles and `ChestScreen`'s share card read the live rule. Needs design sign-off and re-measurement, scheduled before the Form enum can go.
