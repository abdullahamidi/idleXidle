# Package 10 — UX Reference + Asset Placement Guide

This package contains the improved Package 10 reference screens plus an implementation-oriented placement guide that maps each screen back to the asset families already produced for IdleXIdle / IDLExIDLE.

## What is included
- screens/ — clean reference screens
- annotated/ — the same screens with labeled layout regions
- preview/ — contact sheet overview
- docs/IMPLEMENTATION_GUIDE.md — screen-by-screen UX and placement guide
- docs/SCREEN_LAYOUT_SPEC.json — region coordinates and descriptions for every screen
- docs/ASSET_FAMILY_MAPPING.md — which generated asset packages feed each screen

## Important
These screens are reference compositions, not a direct atlas export. Use them to guide your MonoGame scene composition, panel sizing, spacing, and hierarchy while reusing the actual assets from Packages 01–09.
